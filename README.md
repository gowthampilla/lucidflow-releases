# Lucidflow

Find your words. Keep your flow.

Official desktop downloads and release notes for Lucidflow, an interview coaching app for Windows and macOS. This repository distributes release assets; application and backend source are maintained separately.

- [Website, setup and user manual](https://lucidflow-xi.vercel.app/)
- [Latest release](https://github.com/gowthampilla/lucidflow-releases/releases/latest)
- [Administrator dashboard](https://lucidflow-xi.vercel.app/admin/)

## Install

Download the Windows x64 EXE or Apple Silicon Mac DMG from Releases. For Mac, open the DMG and drag Lucidflow into Applications. The current builds are unsigned; the Mac app is not notarized. Intel Mac builds are not included.

Use an administrator-created account to sign in. Provider API keys, model access and usage credits are assigned by the administrator. The desktop user does not need to paste API keys. Review the illustrated PDF manual for setup, recording permissions, all seven keyboard commands and troubleshooting.

Verify installer integrity against the release's `SHA256SUMS.txt` before installation. Download links on the website point to these GitHub release assets.

## Responsible use

Use assistance and audio capture only where permitted. Generated suggestions can be inaccurate. Screen-sharing exclusion varies by platform and capture method and is not guaranteed.
